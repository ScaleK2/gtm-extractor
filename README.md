# GTM Extractor

Exports and structures Google Tag Manager container data for auditing and analysis.

---

# Purpose

This tool:
- exports GTM containers
- extracts tags, triggers, and variables
- structures outputs for reporting workflows

---

# Outputs

- JSON exports
- Structured tabular data
- Google Sheets-ready formatting
